# Do It List

A simple todo list app built with **React** and **Vite**. This project is part of the Code the Dream React course, and it will grow week by week with new features.

## Features

- Displays a title and a list of todos
- Built with reusable React components

## Technologies

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- JavaScript
- ESLint

## Installation

1. Clone the repository:
```bash
   git clone https://github.com/jeloercc/doit-list.git
```
2. Move into the project folder:
```bash
   cd doit-list
```
3. Install the dependencies:
```bash
   npm install
```

## Running the Development Server

Start the server with:

```bash
npm run dev
```

Then open your browser and go to [http://localhost:5173](http://localhost:5173).
